# HAR ARENA 2097 — One Must Fall 오마주 격투 프로토타입

클래식 로봇 격투게임 *One Must Fall: 2097*의 시스템을 오마주한 웹 기반 격투게임
프로토타입입니다. **파일럿과 HAR(로봇)를 따로 골라 조합**하고, 토너먼트에서 번 크레딧으로
기체를 **업그레이드**하며 사다리를 오릅니다. Three.js로 제작되었으며
**단독 HTML 파일 하나로 실행**됩니다. 스토리·기술명·텍스트는 전부 이 프로젝트의
오리지널 창작(오마주)입니다.

![gameplay](docs/screenshot.png)

## 실행 방법

**방법 1 — 단독 파일 (권장)**: `SFvsTK.html` 파일을 브라우저로 열면 끝입니다.
서버·빌드·네트워크 불필요 (three.js 포함 완전 자립형).

**방법 2 — 개발용 모듈 버전**:

```bash
python3 -m http.server 8000   # 저장소 루트에서
# http://localhost:8000 접속 (index.html)
```

타이틀에서 **1** (토너먼트/스토리) / **2** (2인 대전) / **3** (연습장) →
**파일럿 선택 → HAR 선택** → 대전.

## 스토리 (오리지널 오마주 설정)

> 서기 2097년 — 국가는 무너졌고 궤도 기업들이 지구를 나눠 가졌다. 분쟁은 전쟁이 아니라
> 링 위에서 끝난다. 파일럿은 뉴럴 링크로 거대 로봇 HAR과 신경을 동기화해 싸우고,
> 주최사 WAR가 내건 우승 상품은 가니메데 기지의 운영권. 결승 너머에는 총수
> **크라이색**이 비밀 프로토타입 **NOVA**와 함께 기다린다.

토너먼트는 5연전 + 최종 보스전의 사다리 구조이며, 파일럿마다 **고유 엔딩**이 나옵니다.
패배해도 크레딧과 업그레이드는 유지된 채 그 판부터 재도전할 수 있습니다.

| HAR | 스타일 | 스킬(중립) | 앞+스킬 | 뒤+스킬 | ↓+스킬 | 슈퍼 |
|---|---|---|---|---|---|---|
| **일렉트라** | 스피드 · 연격 | 일렉트릭 샤드 (전격탄) | 라이징 볼트 (무적 대공) | 롤링 썬더 (4히트) | 볼트 스윕 (하단) | 썬더 스톰 |

| **재규어** | 러시다운 · 도약 | 컨커션 캐논 (스턴) | 재규어 어퍼 (무적 대공) | 재규어 리프 (돌진) | 로우 파운스 (하단 돌진) | 오버드라이브 리프 |
| **섀도우** | 팬텀 반격 | **팬텀 트랩 (반격기)** | 섀도우 라이즈 (런처) | 트윈 팬텀 (2히트) | 섀도우 스윕 (하단) | 팬텀 러시 |

- 쏜·파이로스는 잡기 전문 기체: 일반 잡기(<kbd>I</kbd>) 데미지가 높고, 스킬(중립) 슬롯의
  커맨드 그랩은 사거리·데미지가 크게 강화된 시그니처 던지기입니다.

## 성장 — 정비고 업그레이드 (토너먼트 모드)

승리할 때마다 크레딧을 벌고 (기본 300¢ + 사다리 보너스 + 퍼펙트 +200¢),
경기 사이 **정비고**에서 기체를 강화합니다. 진행 상황은 localStorage에 저장되어
브라우저를 닫아도 유지됩니다.

| 업그레이드 | 효과 (Lv당, 최대 5) |
|---|---|
| 팔 서보 파워 | 펀치·잡기 데미지 +8% |
| 다리 서보 파워 | 킥 데미지 +8% |
| 구동계 | 이동·점프 +5% |
| 장갑판 | 최대 내구도 +8% |

CPU 상대도 사다리가 올라갈수록 강해지며, 최종 보스 NOVA는 중장갑 + 크라이색 스탯으로 등장합니다.

## 비주얼 — 프리렌더 3D 느낌의 2D 로봇

원작이 3D 렌더링을 2D 스프라이트로 구운 것처럼, 이 프로젝트의 HAR는 **실시간 3D로
셰이딩되지만 깊이를 눌러 납작하게(z×0.78)** 만들어 2D 스프라이트처럼 읽힙니다.
모든 텍스처는 외부 이미지 없이 캔버스로 생성합니다:

- **장갑판**: 브러시드 메탈 + 패널 심 + 리벳 + 전투 스크래치 (컬러맵+범프맵)
- **기체 아이덴티티**: HAR별 발광 바이저/리액터 코어, 마모도가 다른 피니시
  (재규어=야전 마모, 쏜=너덜너덜한 중장갑, 카타나=반짝이는 폴리시드)
- **스테이지**: 가니메데 아레나 — 장갑 데크, 위험 표시 스트라이프, 네온 배리어,
  홀로 광고판, 별하늘에 거대한 목성

## 조작 (4버튼 + 게임패드 지원 🎮)

| | P1 | P2 | 게임패드 (표준 맵핑) |
|---|---|---|---|
| 이동/점프/앉기 | A D / W / S | ← → / ↑ / ↓ | 십자키 · 왼스틱 |
| 펀치 | J | Numpad1, N | X (□) |
| 킥 | K | Numpad2, M | Y (△) |
| 스킬 | L | Numpad3, , | A (✕) |
| 잡기 | I | Numpad5, B | B (○) |
| 슈퍼 매크로 | U | Numpad6, . | LB / RB |

패드 1번 → P1, 패드 2번 → P2. 메뉴도 패드로 조작 가능.

- **가드**: 상대 반대 방향 홀드 (상·중단) / **앉아 가드**: ↓+반대 방향
- **잡기**: 가드 불능
- **스킬 캔슬**: 잽 히트/가드 시 스킬·슈퍼로 캔슬
- **대시**: 이동키 2번 연속 입력. 후방 대시는 초반 살짝 무적, 후반부 공격 캔슬 가능

## 방향 커맨드 노멀

펀치·킥도 누르고 있는 방향에 따라 다른 기술이 나갑니다:

| 입력 | 펀치 | 킥 |
|---|---|---|
| 중립 | 잽 (표준) | 표준 킥 |
| → (전진) | **전진 강타** | **전진 니킥** |
| ← (견제) | **견제 엘보** | **백킥** |
| ↓ (앉아) | 앉아 잽 | 앉아 킥 |

## 모바일 지원

- **가변 해상도**: 화면 크기·방향 전환을 실시간 반영. 좁은 화면에선 HUD가 자동 축소.
- **터치 조작**: 터치 기기에서 가상 패드 + 액션 버튼 자동 표시. 키보드·패드·터치 혼용 가능.

## 시스템 (공방·타격감)

- **스턴(기절) 게이지**: 연속으로 얻어맞으면 기절 수치가 쌓이고 (시간이 지나면 감소),
  한계를 넘으면 **STUNNED!** — 길게 무방비로 비틀거리는 확정 펀시 기회가 생깁니다.
- **스크랩 피니시**: 슈퍼 아츠로 KO를 내면 **SCRAP!** 연출과 함께
  토너먼트 모드에서 +150¢ 파괴 보너스를 받습니다.
- 가드 상성: 상단(앉으면 회피) / 중단 / 하단 / 특수중단
- 카운터 히트, 저글 콤보 (데미지 스케일링), 바운드
- **벽꽝(Wall Splat)** — 좌우 배리어로 강하게 날리면 벽에 박힘 → 벽콤보
- 잡기 3단계 연출 (리치 → 캐치+실행 → 임팩트), 기상 이지선다 (Okizeme)
- 히트스톱 · 화면 흔들림 · 히트 스파크 · 잔상 · 데미지 표기 · KO 슬로모션
- 라운드제 (2선승, 60초), 칩 데미지, WebAudio 신디사이즈 효과음 (외부 에셋 0)
- 슈퍼 게이지: MAX 시 펀치+킥 동시 (또는 <kbd>U</kbd>) → 슈퍼 아츠

## 연습장 모드 (Practice)

타이틀에서 **3** → 파일럿/기체 선택. <kbd>R</kbd> 초기화 · <kbd>G</kbd> 게이지 MAX ·
<kbd>Tab</kbd> 더미 행동 순환 · <kbd>M</kbd> 기술표. 체력은 1에서 멈춰 콤보 반복 연습 가능.

## 프로젝트 구조

```
SFvsTK.html     # ★ 단독 실행 파일 (빌드 산출물, three.js 내장)
index.html      # 개발용 모듈 버전
scripts/build.mjs  # 단독 파일 빌드: node scripts/build.mjs
vendor/         # three.js (벤더링)
src/
  main.js       # 부트스트랩 · 파일럿/HAR 선택 · 토너먼트 사다리 · 정비고 · 카메라 · 메인 루프
  game.js       # 판정 · 가드 상성 · 저글 · 벽꽝 · 잡기 · 반격기 · 슈퍼 · 라운드 · 연습장
  fighter.js    # 기체 상태머신 (이동/공격/피격/다운/기상/대시/게이지/서보 배율)
  moves.js      # 6 HAR 프레임 데이터 + 파일럿 스탯 + NOVA 보스 + 포즈 키프레임
  rig.js        # 절차적 HAR 리그 (장갑 메탈 · 바이저/코어 발광 · z-플랫 스프라이트 룩)
  textures.js   # 절차적 캔버스 텍스처 (메탈/목성/나무/회벽/패브릭 + 범프맵)
  ai.js         # CPU AI (거리 전술 · 반응 가드 · 기상 심리 · 슈퍼)
  fx.js         # 히트스톱 · 셰이크 · 파티클 · 잔상
  stage.js      # 가니메데 아레나 (배리어 벽 · 네온 · 목성 하늘)
  audio.js      # WebAudio 신디사이즈 SFX
  ui.js         # 체력바 · 게이지 · 콤보 · 어나운스 · 연습장 패널
test/           # Playwright 자동 플레이테스트
```

## 빌드 & 테스트

```bash
npm install                # playwright + three (개발 전용)
node scripts/build.mjs     # src/* → SFvsTK.html 단독 파일 생성

npm test                   # 전체 스위트 (부팅/전투/벽꽝/슈퍼/잡기/터치/단독파일)
```
