# SF vs TK — 3D Fighting Game Prototype

스트리트 파이터 × 철권 스타일의 웹 기반 3D 대전 격투게임 프로토타입입니다.
Three.js로 제작되었으며 **단독 HTML 파일 하나로 실행**됩니다.

![gameplay](docs/screenshot.png)

## 실행 방법

**방법 1 — 단독 파일 (권장)**: `SFvsTK.html` 파일을 브라우저로 열면 끝입니다.
서버·빌드·네트워크 불필요 (three.js 포함 완전 자립형, 855KB).

**방법 2 — 개발용 모듈 버전**:

```bash
python3 -m http.server 8000   # 저장소 루트에서
# http://localhost:8000 접속 (index.html)
```

타이틀에서 **1** (VS CPU) / **2** (2인 대전) → 캐릭터 선택 → 대전.

## 캐릭터 (4인)

| | 스타일 | 스킬(중립) | 앞+스킬 | 뒤+스킬 | ↓+스킬 | 슈퍼 아츠 |
|---|---|---|---|---|---|---|
| **춘리** (SF) | 스피드 · 연격 | 기공권 (장풍) | 천승각 (무적 대공) | 백열각 (4히트 연각) | 회전각 (하단) | 봉익선 |
| **니나** (TK) | 한방 · 벽 운반 | 블론드 밤 (초넉백) | 디바인 캐논 (런처) | 아이보리 커터 (회피 런처) | 스위핑 로우 | 사일런트 어썰트 |
| **캐미** (SF) | 러시다운 · 돌진 | 스핀 너클 (스턴) | 캐논 스파이크 (무적 대공) | 스파이럴 애로우 (돌진) | 슬라이딩 (하단 돌진) | 스핀 드라이브 스매셔 |
| **아스카** (TK) | 반격 · 묵직한 한방 | **백로 반격 (반격기)** | 귀신무 (런처) | 선풍연각 (2히트) | 낙엽쓸기 (하단) | 귀신 연무 |

- 아스카의 반격기는 상단·중단 타격을 받아쳐 카운터 — 하단·장풍·잡기에는 뚫립니다.

## 조작 (철권식 4버튼 + 게임패드 지원 🎮)

| | P1 | P2 | 게임패드 (표준 맵핑) |
|---|---|---|---|
| 이동/점프/앉기 | A D / W / S | ← → / ↑ / ↓ | 십자키 · 왼스틱 |
| 펀치 | J | Numpad1, N | X (□) |
| 킥 | K | Numpad2, M | Y (△) |
| 스킬 | L | Numpad3, , | A (✕) |
| 잡기 | I | Numpad5, B | B (○) |
| 슈퍼 매크로 | U | Numpad6, . | LB / RB |

패드 1번 → P1, 패드 2번 → P2. 메뉴도 패드로 조작 가능.

- **가드**: 상대 반대 방향 홀드 (상·중단) / **앉아 가드**: ↓+반대 방향 (하단 방어, 상단 회피 — 중단에 뚫림)
- **잡기**: 가드 불능
- **스킬 캔슬**: 잽 히트/가드 시 스킬·슈퍼로 캔슬 (잽잽 → 런처 / 잽 → 슈퍼)

## 슈퍼 게이지

- 공격 적중·피격·가드로 게이지 축적 (체력바 아래 파란 바)
- **MAX 시 펀치+킥 동시 입력** (또는 슈퍼 매크로 버튼) → 슈퍼 아츠 발동
- 발동 시 슈퍼 프리즈 + 섬광 연출, 무적 돌진 다단히트 (~250 데미지), 가드해도 칩 데미지 큼

## 기상 이지선다 (Okizeme)

다운된 쪽의 선택지 — 일어나는 순간이 심리전입니다:

| 입력 (다운 중) | 행동 |
|---|---|
| 펀치 홀드 | **기상 미들킥** — 무적 판정 후 중단 반격 (가드되면 확정 반격당함) |
| 킥 홀드 | **기상 하단킥** — 하단 반격 + 다운 |
| 뒤 홀드 | **백롤** — 무적 구르기로 거리 벌리기 |
| ↓ 홀드 | **눕기 유지** (최대 1초) — 미티 타이밍 흘리기 |
| 무입력 | 제자리 기상 |

공격측(AI 포함)은 미티 하단 / 미티 런처 / 백스텝 낚시를 섞어 응수합니다.

## 시스템 (공방·타격감)

- 철권식 가드 상성: 상단(앉으면 회피) / 중단 / 하단 / 특수중단
- 카운터 히트 (데미지·경직 보너스), 저글 콤보 (데미지 스케일링), 바운드
- **벽꽝(Wall Splat)** — 좌우 벽으로 강하게 날리면 벽에 박힘 → 벽콤보
- 히트스톱 · 화면 흔들림 · 히트 스파크 · 잔상 · 데미지 표기 · KO 슬로모션
- 라운드제 (2선승, 60초), 칩 데미지, WebAudio 신디사이즈 효과음 (외부 에셋 0)

## 프로젝트 구조

```
SFvsTK.html     # ★ 단독 실행 파일 (빌드 산출물, three.js 내장)
index.html      # 개발용 모듈 버전
scripts/build.mjs  # 단독 파일 빌드: node scripts/build.mjs
vendor/         # three.js (벤더링)
src/
  main.js       # 부트스트랩 · 캐릭터 선택 · 카메라 · 메인 루프
  game.js       # 판정 · 가드 상성 · 저글 · 벽꽝 · 반격기 · 슈퍼 · 라운드
  fighter.js    # 캐릭터 상태머신 (이동/공격/피격/다운/기상/게이지)
  moves.js      # 4캐릭터 프레임 데이터 + 포즈 키프레임
  rig.js        # 절차적 휴머노이드 리그 (헤어스타일/의상 옵션)
  ai.js         # CPU AI (거리 전술 · 반응 가드 · 기상 심리 · 슈퍼)
  fx.js         # 히트스톱 · 셰이크 · 파티클 · 잔상
  stage.js      # 3D 도장 스테이지 (좌우 벽)
  audio.js      # WebAudio 신디사이즈 SFX
  ui.js         # 체력바 · 게이지 · 콤보 · 어나운스
test/           # Playwright 자동 플레이테스트
```

## 빌드 & 테스트

```bash
npm install                # playwright + three (개발 전용)
node scripts/build.mjs     # src/* → SFvsTK.html 단독 파일 생성

python3 -m http.server 8321 &
node test/smoke.mjs        # 부팅 + 기본 조작
node test/playtest.mjs     # KO → 라운드 → 매치 종료 플로우
node test/wallsplat.mjs    # 벽꽝 + 벽콤보
node test/features.mjs     # 캐미/아스카 · 슈퍼 · 기상공격 · 반격기
node test/singlefile.mjs   # 단독 파일 file:// 부팅 검증
```

> 캐릭터 외형·기술명은 기존 격투게임에 대한 오마주로, 박스 기반 로우폴리로 재해석한 프로토타입입니다.
