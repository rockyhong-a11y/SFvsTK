# SF vs TK — 3D Fighting Game Prototype

스트리트 파이터 × 철권 스타일의 웹 기반 3D 대전 격투게임 프로토타입입니다.
Three.js로 제작되었으며 **단독 HTML 파일 하나로 실행**됩니다.

![gameplay](docs/screenshot.png)

## 실행 방법

**방법 1 — 단독 파일 (권장)**: `SFvsTK.html` 파일을 브라우저로 열면 끝입니다.
서버·빌드·네트워크 불필요 (three.js 포함 완전 자립형).

**방법 2 — 개발용 모듈 버전**:

```bash
python3 -m http.server 8000   # 저장소 루트에서
# http://localhost:8000 접속 (index.html)
```

타이틀에서 **1** (VS CPU) / **2** (2인 대전) / **3** (연습장) → 캐릭터 선택 → 대전.

## 캐릭터 (7인)

| | 스타일 | 스킬(중립) | 앞+스킬 | 뒤+스킬 | ↓+스킬 | 슈퍼 아츠 |
|---|---|---|---|---|---|---|
| **춘리** (SF) | 스피드 · 연격 | 기공권 (장풍) | 천승각 (무적 대공) | 백열각 (4히트 연각) | 회전각 (하단) | 봉익선 |
| **니나** (TK) | 한방 · 벽 운반 | 블론드 밤 (초넉백) | 디바인 캐논 (런처) | 아이보리 커터 (회피 런처) | 스위핑 로우 | 사일런트 어썰트 |
| **캐미** (SF) | 러시다운 · 돌진 | 스핀 너클 (스턴) | 캐논 스파이크 (무적 대공) | 스파이럴 애로우 (돌진) | 슬라이딩 (하단 돌진) | 스핀 드라이브 스매셔 |
| **아스카** (TK) | 반격 · 묵직한 한방 | **백로 반격 (반격기)** | 귀신무 (런처) | 선풍연각 (2히트) | 낙엽쓸기 (하단) | 귀신 연무 |
| **장기에프** (SF, 남) | 거구 · 커맨드 그랩 | **스크류 파일드라이버 (커맨드 그랩)** | 배니싱 플랫 | 더블 라리아트 (2히트) | 더블 니 프레스 (하단) | 레드 사이클론 |
| **R. 미카** (SF, 여) | 수플렉스 · 잡기 압박 | **슈팅 피치 수플렉스 (커맨드 그랩)** | 러닝 바디 프레스 (돌진) | 피치 캔 캔 (2히트) | 로우 슬라이드 (하단 돌진) | 미카 익스프레스 |
| **사쿠라** (SF) | 슈토 러시다운 | 하도켄 (장풍) | 쇼오켄 (무적 대공) | 슌푸카큐쿠 (3히트 돌진) | 낮은 스윕 (하단) | 하루이치방 |

- 아스카의 반격기는 상단·중단 타격을 받아쳐 카운터 — 하단·장풍·잡기에는 뚫립니다.
- 장기에프·R. 미카는 잡기 전문 캐릭터: 일반 잡기(<kbd>I</kbd>) 데미지가 높고, 스킬(중립) 슬롯의
  **커맨드 그랩**은 사거리·데미지가 크게 강화된 시그니처 던지기(파일드라이버/수플렉스)입니다.

### 모델 선택 기능 (사쿠라 및 기타 캐릭터)

**캐릭터 선택 화면에서 <kbd>↑</kbd>/<kbd>↓</kbd> (또는 <kbd>W</kbd>/<kbd>S</kbd>)로 캐릭터별 렌더링 방식을 선택할 수 있습니다:**

- **사쿠라**: 기본값은 "Juri" 모델(CC BY 4.0 무료 3D 모델, 완전히 리깅됨)
  - **Juri** — 원본 USFIV 팬아트 모델
  - **Athletic** — 스포츠 여성 모델 (CC BY 4.0)
  - **Tina** — Toon 스타일 모델 (CC BY 4.0)

선택된 모델과 관계없이 **모든 애니메이션(펀치, 킥, 스킬, 슈퍼)은 동일하게 작동**합니다.
모든 모델은 게임의 16키 추상 포즈 시스템으로 실시간 재타게팅되며 ([CREDITS.md](CREDITS.md) 참조),
세계좌표 기준 회전 연산으로 각 모델의 뼈대 구조 차이에 무관하게 일관된 동작을 제공합니다.
(`src/skinnedRig.js` 참고)

## 조작 (철권식 4버튼 + 게임패드 지원 🎮)

| | P1 | P2 | 게임패드 (표준 맵핑) |
|---|---|---|---|
| 이동/점프/앉기 | A D / W / S | ← → / ↑ / ↓ | 십자키 · 왼스틱 |
| 펀치 | J | Numpad1, N | X (□) |
| 킥 | K | Numpad2, M | Y (△) |
| 스킬 | L | Numpad3, , | A (✕) |
| 잡기 | I | Numpad5, B | B (○) |
| 슈퍼 매크로 | U | Numpad6, . | LB / RB |

패드 1번 → P1, 패드 2번 → P2. 메뉴도 패드로 조작 가능.

- **가드**: 상대 반대 방향 홀드 (상·중단) / **앉아 가드**: ↓+반대 방향 (하단 방어, 상단 회피 — 중단에 뚫림)
- **잡기**: 가드 불능
- **스킬 캔슬**: 잽 히트/가드 시 스킬·슈퍼로 캔슬 (잽잽 → 런처 / 잽 → 슈퍼)
- **대시**: 이동키(A/D 또는 ←/→) **2번 연속 입력**으로 전방/후방 대시. 후방 대시는 초반 살짝 무적,
  대시 후반부에는 공격 버튼으로 바로 캔슬 가능 (대시 → 즉시 공격 연계).

## 방향 커맨드 노멀 (펀치·킥도 스킬처럼)

스트리트 파이터처럼 **펀치·킥도 누르고 있는 방향에 따라 전혀 다른 기술**이 나갑니다
(스킬이 중립/앞/뒤/아래 4방향으로 갈리는 것과 동일한 원리):

| 입력 | 펀치 | 킥 |
|---|---|---|
| 중립 | 잽 (표준) | 표준 킥 |
| → (전진) | **전진 강타** — 짧은 전진 + 고데미지 | **전진 니킥** — 전진 + 리치 확보 |
| ← (견제) | **견제 엘보** — 빠르고 안전한 견제기 | **백킥** — 큰 넉백의 회전 백킥 |
| ↓ (앉아) | 앉아 잽 (기존) | 앉아 킥 (기존) |

## 모바일 지원

- **가변 해상도**: 뷰포트/캔버스가 화면 크기·방향 전환(orientationchange)·모바일 브라우저의
  주소창 접힘까지 실시간으로 반영해 리사이즈됩니다. 좁은 화면에서는 HUD·메뉴 폰트/여백이
  자동으로 축소되고, 세로 모드에서는 가로 모드 전환을 안내합니다.
- **터치 조작**: 터치 기기를 자동 감지해 화면 하단에 가상 패드(방향 4버튼)와
  액션 버튼(펀치·킥·스킬·잡기·슈퍼)을 표시합니다. 방향 버튼 2번 연타로 대시도 동일하게
  동작하며, 키보드·게임패드·터치를 동시에 섞어 쓸 수 있습니다. 데스크톱(마우스+키보드)
  환경에서는 자동으로 숨겨집니다.

## 잡기 시스템 (전후 애니메이션 명확화)

잡기는 더 이상 프레임이 생략되지 않고, 3단계로 뚜렷하게 분리되어 재생됩니다:

1. **리치(헛손질 가능)** — 손을 뻗는 시동 동작. 이 시점에 빗나가면 그대로 경직.
2. **캐치 + 실행** — 잡기가 성공하면 공격자·피격자가 하나의 공유 타임라인으로 잠기고,
   업어치기/수플렉스/파일드라이버 등 스타일별 전용 키프레임으로 두 캐릭터가 함께 움직입니다.
3. **임팩트** — 데미지 적용과 동시에 피격자가 일반 히트/다운 리액션으로 자연스럽게 전환됩니다.

## 슈퍼 게이지

- 공격 적중·피격·가드로 게이지 축적 (체력바 아래 파란 바)
- **MAX 시 펀치+킥 동시 입력** (또는 슈퍼 매크로 버튼) → 슈퍼 아츠 발동
- 발동 시 슈퍼 프리즈 + 섬광 연출, 무적 돌진 다단히트 (~250 데미지), 가드해도 칩 데미지 큼

## 기상 이지선다 (Okizeme)

다운된 쪽의 선택지 — 일어나는 순간이 심리전입니다:

| 입력 (다운 중) | 행동 |
|---|---|
| 펀치 홀드 | **기상 미들킥** — 무적 판정 후 중단 반격 (가드되면 확정 반격당함) |
| 킥 홀드 | **기상 하단킥** — 하단 반격 + 다운 |
| 뒤 홀드 | **백롤** — 무적 구르기로 거리 벌리기 |
| ↓ 홀드 | **눕기 유지** (최대 1초) — 미티 타이밍 흘리기 |
| 무입력 | 제자리 기상 |

공격측(AI 포함)은 미티 하단 / 미티 런처 / 백스텝 낚시를 섞어 응수합니다.

## 일시정지 메뉴

대전 중 <kbd>P</kbd> 또는 <kbd>Esc</kbd>로 일시정지 → **계속하기 / 라운드 재시작 / 메인 메뉴로 나가기**
중 선택 (↑↓ + Enter, 마우스, 게임패드 모두 지원). 아래에 양쪽 캐릭터의 스킬 커맨드 표도 함께 표시됩니다.

## 연습장 모드 (Practice)

타이틀에서 **3**을 눌러 진입. 플레이어 캐릭터와 더미 캐릭터를 순서대로 선택합니다.

| 키 | 기능 |
|---|---|
| <kbd>R</kbd> | 위치 · 체력 초기화 (게이지는 MAX 토글 상태 유지) |
| <kbd>G</kbd> | **게이지 MAX 토글** — 양쪽 슈퍼 게이지를 강제로 가득 채운 채 유지 |
| <kbd>Tab</kbd> | 더미 행동 순환: 대기 → 가드 → 앉아가드 → CPU |
| <kbd>M</kbd> | 플레이어 캐릭터의 기술표 패널 토글 |

연습장에서는 라운드 타이머·KO·승패 판정이 없으며, 체력은 0이 아닌 **1에서 멈춰** 콤보를
몇 번이고 반복 연습할 수 있습니다.

## 시스템 (공방·타격감)

- 철권식 가드 상성: 상단(앉으면 회피) / 중단 / 하단 / 특수중단
- 카운터 히트 (데미지·경직 보너스), 저글 콤보 (데미지 스케일링), 바운드
- **벽꽝(Wall Splat)** — 좌우 벽으로 강하게 날리면 벽에 박힘 → 벽콤보
- 히트스톱 · 화면 흔들림 · 히트 스파크 · 잔상 · 데미지 표기 · KO 슬로모션
- 라운드제 (2선승, 60초), 칩 데미지, WebAudio 신디사이즈 효과음 (외부 에셋 0)

## 빌드 & 테스트

```bash
npm install                # playwright + three (개발 전용)
node scripts/build.mjs     # src/* → SFvsTK.html 단독 파일 생성

python3 -m http.server 8321 &
node test/smoke.mjs        # 부팅 + 기본 조작
node test/playtest.mjs     # KO → 라운드 → 매치 종료 플로우
node test/wallsplat.mjs    # 벽꽝 + 벽콤보
node test/features.mjs     # 캐미/아스카 · 슈퍼 · 기상공격 · 반격기
node test/v2features.mjs   # 잡기 애니메이션 · 장기에프/미카 · 대시 · 일시정지 메뉴 · 연습장
node test/cmdnormals.mjs   # 방향별 커맨드 노멀 (전진/견제 펀치·킥)
node test/touch.mjs        # 터치 오버레이 · 가상 패드/버튼 입력
node test/desktopnotouch.mjs  # 데스크톱에서 터치 UI 비표시 확인
node test/sakura.mjs       # 사쿠라(리깅 모델) 선택·로드·기술 검증
node test/variants.mjs     # 모델 선택 UI · 위/아래 키 사이클링 · 모델 로드 검증
node test/singlefile.mjs   # 단독 파일 file:// 부팅 검증
node test/singlefile2.mjs  # 단독 파일에서 연습장 + 커맨드 그랩 검증
node test/singlefile3.mjs  # 단독 파일에서 터치 조작 + 커맨드 노멀 검증
node test/singlefile4.mjs  # 단독 파일에서 사쿠라(base64 내장 GLB) 검증
```
